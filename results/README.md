# Results (generated)

Scripts write comparison grids, metric charts, and quantized inference outputs here (e.g. `compare_fp_w8_w6_w4_all.png`, `metrics_comparison.png`, `convit_ptq/`, `convit_ptq4vit/`).

This folder is mostly empty in a fresh clone; run the `convit/` or `pvt/` entry points after placing checkpoints in `../checkpoints/`.
